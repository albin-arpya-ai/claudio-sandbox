# claudio-sandbox

A throwaway repository for Claudio, the software engineer agent, to practise on.

Nothing here matters. It exists so that a full run — clone, branch, edit, test,
push, open a PR — can be exercised end to end against a real remote, without a
real repository being involved.

It is **public on purpose**: branch protection is free on public repositories, so
the "Claudio can never merge" fence can be proven here at no cost before deciding
how to pay for it on private repos.

Agent: https://github.com/albin-arpya-ai/software-engineer-agent

## Running the tests

```bash
pytest -q
```
